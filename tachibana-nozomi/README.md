# Tachibana Nozomi Codex 桌面宠物

## 角色说明

本桌宠对应的角色名称为 **Tachibana Nozomi**。

本包的原始桌宠元数据对其形象的描述如下：

> Pixel pet of Tachibana Nozomi: a mischievous light-green-haired chibi officer girl with peaked cap, blue armband, gloves, halo, pointed ears, and tail.

原始包未附可核实的角色出处或人物设定来源。为避免编造，本说明不扩写角色履历、关系或剧情；相关设定请以原作及权利方公开资料为准。

## 安装方式

1. 下载或复制本仓库中的 `tachibana-nozomi` 文件夹。
2. 将整个文件夹放入 Codex 宠物目录，例如：

   ```text
   C:\Users\<你的用户名>\.codex\pets\
   ```

3. 放置完成后的路径应类似：

   ```text
   C:\Users\<你的用户名>\.codex\pets\tachibana-nozomi\pet.json
   C:\Users\<你的用户名>\.codex\pets\tachibana-nozomi\spritesheet.webp
   ```

4. 重新打开或刷新 Codex 的桌面宠物功能后，选择 `Tachibana Nozomi` 即可使用。

## 文件结构

```text
tachibana-nozomi/
  README.md
  pet.json
  spritesheet.webp
```

- `pet.json`：宠物元数据（当前包使用精灵图版本 1）。
- `spritesheet.webp`：桌宠动画图集。
